# Z.的法术笔记 (ZSpells) v1.2

[English README](README.md)

这个MOD将拥王者和无冬之夜的部分法术添加到博德之门游戏中。仅增强版游戏可用。

安装后可以在商店里购买Z的法术笔记进行学习，一共有13本不同的笔记：

- Z的PF法术笔记-重挫冲击
- Z的PF法术笔记-法师护甲系列
- Z的PF法术笔记-初级变化系-属性增强
- Z的PF法术笔记-变化系-防御，破隐与逃跑
- Z的PF法术笔记-附魔系-强化
- Z的PF法术笔记-毁灭
- Z的PF法术笔记-死灵系
- Z的法术笔记-原创-腐化元素
- Z的PF法术笔记-咒法与元素
- Z的PF法术笔记-防护与破法
- Z的神话法术笔记-绝杀术
- Z的神话法术笔记-腐化魔法
- Z的神话法术笔记-三重祈愿

可以在下列商店购买这些笔记：

- 泰蓝提尔（高篱堡）
- 哈巴瑟·德林（巫术杂货店，仅龙矛）
- 利博德（冒险者集市）
- 拉札卢斯·李巴卢斯（萨拉督许）

如果安装了IWD1_EET、IWD2_EET，还可以在下列商店购买：

- 灰袍欧瑞克 Orrick（库达哈 Kuldahar）
- 伊蕾瑟拉 Elytharra（塔尔歌斯城 Targos Town）

如果安装MOD之前已经访问过这些商店，就需要重新开始游戏。

## 已加入的法术

**1级法术：** 法师护甲I（PF）、脚底抹油（PF）、变巨术（PF）、缩小术（PF）、护盾术（PF）

**2级法术：** 牛之蛮力、猫之轻灵、熊之坚韧、狐之狡黠、枭之睿智、鹰之威仪、野性之力（NWN2法术）

**3级法术：** 英雄气概（PF）、狂暴术（PF，野蛮人的狂怒）、锐锋术（PF）、重挫冲击（PF）

**4级法术：** 法师护甲II（PF）、繁彩法珠（NWN2版）、可控火球术（4级法术，无友伤的火球术）、弱等红宝石逆转射线

**5级法术：** 回声定位（PF，变化系的真视术）、群体石肤术（PF，需要支付材料费）、强力狂暴术（狂战士的狂暴攻击）、腐化元素爆弹（原创）

**6级法术：** 高等英雄气概（PF）、重挫冲击（升阶/穿刺，超魔版本的重挫冲击，无视魔抗）、地狱烈焰射线（多用用就知道博得和正义之怒有什么不同了）、解离术（PF版）、高等移除魔法

**7级法术：** 法师护甲III（PF）、死亡一指（PF版）、不死归亡（NW版，无冬的版本，图标还是用的PF）、高等法术护盾、高等破解术

**8级法术：** 风暴束、重挫冲击（升阶/穿刺/增效）、高等腐化元素爆弹（原创）

**9级法术：** 法师护甲IV（PF）、英雄祈神、女妖之嚎（PF版）、群体高等法术护盾、法师裂解术

**神话法术：** 绝杀术、腐化魔法、三重祈愿

## 强化铁砧专用组件

这个MOD还包括了额外2个仅限强化铁砧的安装选项，分别是：

- 恢复原版的投影术、拟象术、法术陷阱和连锁意外术（移除消解之手、谭森局部变形术和七级召唤怪物术）
- 恢复原版的大法师之杖

## 神话法术的修习条件

注意：学习神话法术需满足以下条件：

- 人物等级不低于20
- 智慧属性高于22
- 习得时将永久失去1点智慧与100000点经验值

神话法术为天生能力，无需记忆。重复研读神话法术笔记可以增加使用次数。施展神话法术也需要付出相应的代价。

## 更新历史

### v1.2

- 增加了一本新的法术笔记：Z的PF法术笔记-防护与破法。
- 增加了新的法术：
  - 弱等红宝石逆转射线（4级法术，可移除一个5级或以下的法术防护）
  - 高等移除魔法（6级法术，以高15级进行解除魔法判定）
  - 高等法术护盾（7级法术，4轮内免疫解除魔法）
  - 高等破解术（7级法术，可以对巫妖和邪兽鬼生效）
  - 群体高等法术护盾（9级法术，高等法术护盾群体版）
  - 法师裂解术（9级法术，必定解除魔法。除非目标被“法术免疫-防护系”保护）
- Z的PF法术笔记-毁灭 增加了一个新的法术：可控火球术（4级法术，无友伤的火球术）。
- 增加了三本神话法术笔记：Z的神话法术笔记-绝杀术、Z的神话法术笔记-腐化魔法、Z的神话法术笔记-三重祈愿。
- 原法术修改：风暴束增加了视觉效果。

### v1.1

- 调整了大部分法术的持续时间。
- 增加了一本新的法术笔记：Z的PF法术笔记-咒法与元素。
- 增加了新的法术：野性之力（NWN2法术）、次级繁彩法珠（整合至博得3和NWN2）、繁彩法珠（整合至博得3和NWN2）、幽影护盾（NWN法术）。
